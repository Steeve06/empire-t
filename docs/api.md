# API reference

The REST API lives under `/api/v1/`. Its contract is the OpenAPI 3 schema generated by drf-spectacular:

| | |
|---|---|
| Interactive reference (Swagger UI) | `/api/v1/docs/` |
| Readable reference (ReDoc) | `/api/v1/redoc/` |
| Schema | `/api/v1/schema/`, committed as [`packages/api-client/openapi.yaml`](../packages/api-client/openapi.yaml) |

Locally: <http://localhost:8000/api/v1/docs/>.

## Conventions

- **Language:** `?lang=fr` (default) or `?lang=en` selects translated content and the language of validation messages. The parameter wins over `Accept-Language`, so URLs make good cache keys.
- **Errors:** standard DRF shape. A field error is `{"phone": ["Invalid number…"]}`; a general error is `{"detail": "…"}`; a cross-field error is `{"non_field_errors": ["…"]}`.
- **Pagination:** list endpoints that can grow (`services/`, `gallery/`) return `{count, next, previous, results}` with 24 items per page (`?page=2`). Small lists return plain arrays.
- **Images:** `{src, srcset, width, height}` or `null`. `srcset` lists WebP variants at 480, 960 and 1600 px (never upscaled). URLs are root-relative (`/media/...`) unless object storage is configured.
- **Caching:** reads send `Cache-Control` and are cached in Redis until any content changes in the admin.
- **Writes:** throttled per IP (bookings 10 per hour, applications 5, contact 5) and carry a honeypot field `website`, which must stay empty.

## Endpoints

| Method | Path | Description |
|---|---|---|
| GET | `site/` | Shop identity, WhatsApp, address, hours, map, social links, recruitment status, About story, amenities, signature service, main photos |
| GET | `categories/` | Price menu: active categories with nested active services and starting price |
| GET | `categories/{slug}/` | One category (`men`, `women`, `kids`, `beauty`, `packs`) |
| GET | `services/?category=&popular=` | Active services, paginated; `popular=true` for « Tarifs populaires » |
| GET | `services/{slug}/` | One service |
| GET | `supplements/` | Extras (scalp massage, hot towel…) |
| GET | `gallery/?category=&featured=&page=` | Published photos; categories `cuts`, `hairstyles`, `beauty`, `salon` |
| GET | `testimonials/` | Published reviews |
| GET | `team/` | Active team members |
| GET | `careers/openings/` | Open positions; empty after the recruitment deadline |
| GET | `bookings/slots/?date=YYYY-MM-DD&service=` | Start times still available that day (respects hours, notice and service duration) |
| POST | `bookings/` | Booking request; returns the reference and the prefilled WhatsApp link |
| POST | `careers/applications/` | Application, `multipart/form-data` with one or more `files` |
| POST | `contact/` | Contact message |
| GET | `health/` | `{"database":"ok","cache":"ok"}`, 503 when the database is down |

### Example: booking

```http
POST /api/v1/bookings/?lang=fr
Content-Type: application/json

{
  "service": "skin-fade",
  "date": "2026-11-05",
  "time_slot": "15:30",
  "customer_name": "Awa Ngono",
  "phone": "6 99 00 11 22",
  "notes": "",
  "channel": "website",
  "website": ""
}
```

```http
HTTP/1.1 201 Created

{
  "reference": "ET-3WF9H2",
  "status": "new",
  "service": "skin-fade",
  "service_name": "Skin Fade",
  "date": "2026-11-05",
  "time_slot": "15:30",
  "customer_name": "Awa Ngono",
  "whatsapp_url": "https://wa.me/237653147512?text=Bonjour%20Empire%20T%20%21%20Je%20souhaite%20r%C3%A9server…"
}
```

A refused slot returns `400` with `{"time_slot": ["Ce créneau n'est pas disponible. Choisissez une autre heure."]}`.

### Example: application

```bash
curl -X POST "https://empire-t.cm/api/v1/careers/applications/?lang=en" \
  -F opening=barber-titulaire -F full_name="Paul Mbarga" -F contact=653147512 \
  -F files=@cv.pdf -F files=@cni.jpg
```

Accepted files: PDF, Word, JPEG, PNG, WebP, HEIC, MP4, MOV. Up to 8 files, 15 MB each and 40 MB in total, checked by content as well as extension.

## Keeping the frontend in sync

After changing a serializer or view:

```bash
make api-client      # exports openapi.yaml, then regenerates packages/api-client/src/schema.d.ts
pnpm -r typecheck    # every frontend use of a changed field now fails to compile
```

CI fails if `openapi.yaml` or the generated types fall behind the code.
